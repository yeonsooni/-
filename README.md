# 보광중앙교회 (Bogwang Central Church) 홈페이지

광성교회(kwangsung.org) 스타일을 참고하여 제작한 교회 홈페이지입니다.
순수 HTML/CSS/JavaScript로 만들어져 별도의 빌드 과정 없이 바로 배포할 수 있습니다.

## 구성

```
.
├── index.html          # 메인 홈페이지 (히어로 슬라이더, 빠른메뉴, 예배안내, 설교, 소식, 사역)
├── css/
│   └── style.css       # 전체 스타일 (네이비 + 골드 톤, 반응형)
├── js/
│   ├── main.js         # 헤더 스크롤, 모바일 메뉴, 히어로 슬라이더, 스크롤 애니메이션
│   └── footer.js       # 하위 페이지 공통 푸터 삽입
└── pages/
    ├── about.html      # 교회소개 (인사말·비전·연혁)
    ├── worship.html    # 예배안내 (예배시간·온라인예배)
    ├── sermons.html    # 설교말씀
    ├── news.html       # 교회소식 (공지·주보·갤러리)
    ├── ministry.html   # 교육·훈련 (교회학교·청년부·제자훈련·선교)
    └── location.html   # 오시는 길 (지도·교통·주차)
```

## 주요 특징

- **반응형 디자인** — 데스크톱/태블릿/모바일 대응, 모바일 햄버거 메뉴
- **히어로 슬라이더** — 자동 전환 + 도트 네비게이션
- **드롭다운 네비게이션** — 메뉴별 하위 항목
- **스크롤 애니메이션** — 섹션 등장 효과
- 폰트: Noto Sans KR / Noto Serif KR, 아이콘: Font Awesome

## 실행 방법

정적 파일이므로 아무 웹서버로나 열 수 있습니다.

```bash
# 예: 파이썬 내장 서버
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 커스터마이징

- 교회명/주소/연락처: 각 HTML의 헤더·푸터와 `js/footer.js`
- 색상 테마: `css/style.css` 상단의 `:root` 변수(`--navy`, `--gold` 등)
- 예배 시간, 설교 목록, 공지사항: 해당 페이지의 마크업 직접 수정
- 이미지: 현재 Unsplash 예시 이미지를 사용 중이며 실제 교회 사진으로 교체하면 됩니다.
